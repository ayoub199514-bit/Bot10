# Signal AI — بوت تحليل الشموع

هذا المشروع يعطي واجهة مشابهة للنمط الموجود في الصورة:
- SIGNAL / AI
- CALL / PUT / WAIT
- نسبة ثقة تحليلية
- عداد مدة الإشارة
- أسباب فنية
- زر واحد للوسيط
- تحليل صورة الشارت عبر نموذج رؤية AI

## طرق إدخال الصورة
- **لصق مباشر (Ctrl+V)**: انسخ سكرين شات من المتصفح أو أي مكان، وألصقه في الصفحة مباشرة — هذه الطريقة الأساسية.
- **سحب وإفلات** الصورة على منطقة الرفع.
- **لصق رابط صورة مباشر** (يبدأ بـ http/https وينتهي بصيغة PNG/JPG/WebP) — يجلبها الخادم ويحوّلها تلقائيا.
- اختيار ملف من الجهاز كخيار احتياطي.

ملاحظة: لا يوجد ربط فعلي بحساب الوسيط لسحب بيانات مباشرة، لأن منصات مثل Pocket Option لا تقدّم API عام للحسابات الفردية. زر "فتح التداول مع الوسيط" يفتح موقع الوسيط في تبويب جديد فقط.

## التشغيل

1. ثبّت Node.js 18+.
2. افتح المجلد في Terminal.
3. نفّذ:
   npm install
4. انسخ `.env.example` إلى `.env`.
5. ضع مفتاح API في `OPENAI_API_KEY`.
6. شغّل:
   npm start
7. افتح:
   http://localhost:3000

## مهم
الواجهة لا تنفذ الصفقات تلقائيا. التحليل يعتمد على الصورة المرفوعة، لذلك لا يمكن اعتباره بيانات سوق مباشرة أو ضمانا للربح. اختبر أولا على الحساب التجريبي.

## تطوير لاحق
للوصول إلى مستوى أقرب للـ Signal Bots الحقيقي يمكن إضافة مصدر بيانات شموع حيّ، حساب RSI/EMA/MACD على بيانات OHLC، ثم استخدام AI كطبقة تأكيد بدل الاعتماد على الصورة وحدها.
